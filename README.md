# My Budget Tracker

## Project overview

My Budget Tracker is a beginner-friendly webpage built with HTML and CSS. It provides a simple layout for entering and reviewing everyday expenses. This project extends the original Week 1 Budget Tracker.

## Project files

- **`index.html`** – contains the webpage structure, page heading and wallet image, expense form, category dropdown, sample expense table, collapsible help section, and embedded budgeting video.
- **`style.css`** – controls the appearance of the page, including spacing, colours, form fields, table borders, alternating table rows, hover and focus states, and responsive layout.
- **`README.md`** – explains the purpose of the project and what each file does.

## Features included

1. An expense table with a `<thead>`, `<tbody>`, four column headings, and five sample expense rows.
2. An expense form with labelled fields and matching IDs.
3. A category dropdown with Food, Transport, Rent, Entertainment, and Other.
4. An **Add Expense** button with `type="button"`. It is intentionally not connected to JavaScript yet.
5. A wallet icon image with `src`, `alt`, and `width` attributes.
6. An embedded YouTube budgeting video using an `<iframe>`.
7. A collapsible help section using `<details>` and `<summary>`.
8. CSS selectors including a descendant selector, direct-child selector, `:nth-child(even)`, `:not()`, and `:focus`.
9. Table row hover styling and a pointer cursor on the button.

## How to view the project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Keep an internet connection available to load the wallet icon and embedded YouTube video.

## Note

The five expenses are sample records. The Add Expense button is a placeholder for a future JavaScript lesson and does not yet add new rows to the table.
